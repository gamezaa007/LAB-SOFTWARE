# LAB-SOFTWARE — แบบฝึกหัดเขียนโปรแกรม C++

รวมโปรแกรม C++ จากปฏิบัติการวิชาเขียนโปรแกรม แต่ละไฟล์คือโจทย์ 1 ข้อ
ทุกโปรแกรมรับค่าจากคีย์บอร์ด (`cin`) และแสดงผลออกหน้าจอ (`cout`) ตามรูปแบบในตัวอย่างของโจทย์

ไฟล์ทั้งหมดอยู่ในโฟลเดอร์ [`lab/`](lab/)

## วิธีคอมไพล์และรัน

ต้องมีคอมไพเลอร์ C++ เช่น `g++` (บน Windows ใช้ [MSYS2](https://www.msys2.org/) หรือ MinGW)

```bash
cd lab
g++ "LAB01(โปรแกรมตรวจสอบเลขคู่ หรือเลขคี่).cpp" -o lab01
./lab01
```

หรือเปิดไฟล์ใน VS Code แล้วกดปุ่ม Run
